# Descision-Die
Dont know what to choose? the descision die will choose it for you!

<img width="320" height="292" alt="image" src="https://github.com/user-attachments/assets/4ca76d9c-1db4-4284-8966-deafd2638508" />

it uses a seeduino xiao and an imu (MPU6050) to sense if the die has been shaken and outputs results to the 91' oled. it has 4 modes Descision,Die,Coin flip and a random mode(all of the modes mixedup let fate choose for you.

# Design
<img width="268" height="283" alt="image" src="https://github.com/user-attachments/assets/3361489d-0332-4274-babb-bd7bd47ac004" />

i designed the case with tinkercad using m3 holes for the top. it has a button hole and a type c hole for the microcontroller.
